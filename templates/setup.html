Gmail OAuth Credentials
This allows the system to send emails and monitor your inbox for recruiter responses. You can skip this now and configure it later.
How to get your Gmail credentials file
  1. Go to console.cloud.google.com and sign in.
  2. Create a new project (or select an existing one).
  3. In the search bar, search for Gmail API and click Enable.
  4. Go to OAuth consent screen → select External → fill in App name → add your email as a Test User.
  5. Go to Credentials → + Create Credentials → OAuth client ID.
  6. Choose Desktop app as the application type → click Create.
  7. Click Download JSON and upload that file below.
